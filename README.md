## 🔧 Под капотом

```
┌──────────────────────────────────────┐
│  AmanesiaVIP · Multi-Node · Multi-Proto │
├──────────────────────────────────────┤
│  Панель        RosPanel (собственный форк) │
│  Ядра          Xray-core · sing-box · amneziawg-go │
│  Протоколы     VLESS XHTTP (packet-up, CDN) │
│                VLESS Reality │
│                Hysteria 2 │
│                AmneziaWG 3.1 │
│                NaiveProxy · AnyTLS · Mieru │
│  Фронты        CDNvideo / Selectel CDN │
│  Маршрутизация RU → direct · WORLD → VPN │
│  Маскировка    decoy-сайты на узлах, TLS-фронты │
│  Клиенты       Happ · AmneMini · v2rayNG · … │
└──────────────────────────────────────┘
```

- **VLESS XHTTP packet-up** поверх CDN: трафик идёт через край CDN-сети, реальные IP узлов не светятся клиентам и сканерам.
- **Reality** маскирует рукопожатие под TLS к крупным сайтам — без собственных сертификатов, которые можно выявить.
- **AmneziaWG 3.1** — WireGuard с шумовыми паттернами против DPI-блокировок QUIC/WireGuard.
- **Hysteria2** на QUIC выжимает максимум из «плохого» мобильного канала.
- **Decoy-маскировка**: каждый узел отдаёт на 443 обычный сайт (кинотеатр, файловое хранилище, стриминг) — проверь узел браузером и увидишь сайт, а не VPN.
- Собственный форк панели с алертами, аудит-журналом, биллингом и Telegram MiniApp — обновления приезжают на все узлы централизованно.

## ❓ FAQ

**Чем AmanesiaVIP отличается от бесплатных VPN?**
Бесплатные продают тебя (логи, рекламу, трафик). У нас: лимит пользователей на узел, собственные decoy-сайты, CDN-фронты, шесть протоколов и поддержка, которая отвечает в Telegram, а не «в течение 3 рабочих дней».

**Меня заблокируют? Это вообще легально выглядит?**
Узлы маскируются под обычные сайты, трафик неотличим от HTTPS популярных сервисов. Мы не храним логи посещений — технически нечего хранить: учёт только по объёму трафика на подписку.

**Сколько устройств можно привязать?**
Зависит от тарифа — лимит виден в кабинете. Освободить слот (отвязать старое устройство) можно самому, без поддержки.

**Что делать, если протокол «не идёт» на моём провайдере?**
В подписке шесть протоколов: переключись на другой в приложении — обычно этого хватает. Если нет — напиши в поддержку, подскажем рабочий фронт (CDN-домен) под твой регион.

**Как перенести подписку на новый телефон?**
Открой страницу подписки на новом устройстве, нажми «Подключить» — или отвяжи старое устройство в кабинете и привяжи новое.

**Есть ли пробный период?**
Мы не делаем «бесплатных триалов», потому что их мгновенно съедают боты, а узлы забиваются. Зато есть рефералка: привёл друга — получил половину его первого платежа себе на баланс.
